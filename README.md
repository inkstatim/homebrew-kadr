# Homebrew tap для Kadr

[Kadr](https://github.com/inkstatim/kadr-releases) — бесплатное приложение для скриншотов и записи экрана на macOS.

```bash
brew install inkstatim/kadr/kadr
```

Обновление: `brew upgrade kadr` (Kadr и сам предлагает обновления). Удаление: `brew uninstall kadr`.
